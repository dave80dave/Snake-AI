# Snake Backend

Das Spring-Boot-Backend stellt die vorhandene Snake-Engine als JSON-API bereit.

## Starten

Zuerst die Engine im Repository-Hauptordner installieren:

```bash
./mvnw install
```

Danach das Backend starten:

```bash
cd backend
./mvnw spring-boot:run
```

Das Backend ist anschließend unter `http://localhost:8080` erreichbar.
